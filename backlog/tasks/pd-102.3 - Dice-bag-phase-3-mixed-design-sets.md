2026-11-12 phase 3 done. Mixed sets: a die per term can use another bag design: d20@amethyst (dashes as underscores) in the notation, a 'Dice use' picker for the + / - buttons and a chip per term (tap to remove); rolls use pending edits; result line names the design; a ref to a deleted design falls back to the live design. Render path: lookFromDesign / makeUniforms / paintLook give every design its own look and uniform set; shared parts cache (atlas + geometry per shape and number style). Profiling (scripts/profile.mjs, run through the test lock, software GL so ratios only): design switch 2-24 ms and no texture leak; mixing designs costs nothing extra by itself; BEFORE the cache 20 identical d20 held 45 textures (about 14 MB each, build 123 ms, first frame 110 s in swiftshader), AFTER 7 textures, build 6 ms, first frame 6.5 s; mixed 20 d20 across 4 designs first frame 183 s -> 26 s. Clear epoxy is 4.5x the frame cost of other substrates: see the new perf card. Tests: bagbrowser.spec (mixed set, deleted design, shared atlas). Full suite 89 passed, 1 known flaky. Not done: per-design material cache across rebuilds is not needed (materials are cheap); set thumbnails still pending (phase 4).
