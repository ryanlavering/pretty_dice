## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Owner (v24, #bagdirty): a clean bag shows as modified after editing just the roll set on the mat. The roll set is a draft and must not dirty the bag unless saved.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Cause: syncLive() copied the live shape and notation (the roll formula) into the saved design of an unmodified bag design, and the signature also included the draft's shape/notation, so any roll-set edit changed the bag signature. Now the saved design's shape follows the live shape only for a single die (never Custom/Standard 7), the notation is never copied, and the draft part of the signature ignores shape/notation. Named sets were never mutated by roll-set edits (only setOps.update/edit do); the spec asserts sets, design notations and pending are unchanged.

Owner resolved the artifact thread (resolve = ok), 2026-11-18.
