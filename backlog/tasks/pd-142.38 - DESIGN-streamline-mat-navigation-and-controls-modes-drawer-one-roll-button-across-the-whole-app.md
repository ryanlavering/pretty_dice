## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Owner direction 2026-11-14 (from playtest .17, supersedes it). 'The UI and modes are getting confusing and we're collecting too many controls. We need a more streamlined way to switch between views from the main mat that uses less clutter. This needs to be a thoughtful redesign winding through the whole app surface. We're not far off, but we need consistent patterns so the path to each screen is clear.'

Owner's starting points:
1. Primary A|B split: Design/Inventory mode (shape, look, bag, sets, editor) is basically distinct from Roll/Game mode (rolling, quick roll bar, games, log). One clear switch between the two.
2. Utility controls collapse into ONE pop-out drawer: sound, play/pause, and the MISSING reset-camera control (more as found).
3. Too many 'roll' buttons: the owner wants the gesture plus exactly ONE roll button on screen at any moment (today: round button, r key, quick roll bar Roll, Games panel Roll, Bank/Roll in game strips, etc.).
4. Consistent patterns so the path to each screen is obvious (where do bag, sets, games, log, settings, scorecard live and how do you get there).
Existing rules to keep: collapsed menus never hold one item; a collapsed menu starts as a wide pill and slides to a button with an overlapping-circles stack cue; distinct ring colours; game mode hides the mat total and the strip is the top-down handle (PD-142.34); phone layout has the [Settings | Scorecard] tab slot (PD-142.30).

Deliverables, in order: (1) control inventory: every on-screen control and gesture today, per mode, phone and desktop, with duplicates marked (docs/design/ui-controls-audit.md; screenshots from the running app, not source guessing); (2) 2-3 proposals with ASCII/HTML mock-ups for the A|B split, the utility drawer and the single roll control, plus a recommendation; (3) owner review and choice; (4) a migration plan that lands in slices without breaking the lanes; (5) build. Suggest doing the design in a fresh session with Opus (design/planning), then Sonnet for the build.

Constraint for lanes until this lands: do not add new top-level mat buttons or new roll buttons; put new surfaces (initiative tracker, table lookup, Liar's Dice panel, etc.) in existing panels/tabs/drawer slots and note where in the REVIEW line.
