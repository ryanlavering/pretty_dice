## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Owner request 2026-11-13.

UI (games-ui): draw the Craps betting area as a realistic-ish craps table layout instead of the grouped buttons/scoresheet list: pass line, don't pass, come / don't come, field, place numbers 4/5/6/8/9/10, big 6/8, hardways, one-roll props (any seven, any craps, 2, 3, 11, 12, horn), point puck (ON/OFF) on the numbers. Bets are shown as chip stacks on their spot (denominations, stacked, count readable), per player colour where several players bet. Tap a spot to add a bet unit, tap/long-press a chip stack to take down (one unit or the whole bet). Must work in the phone layout from PD-142.30 (compact variant: scrollable or zoomable table; never cover the dice) and keep the per-bet help text (tooltip / Rules).

Engine + rules (games-core): bets must be placed in VALID INTEGER UNITS so payouts are whole chips, not rounded down. Per-bet minimum increment, exposed in suggest() rows as e.g. unit and min: place 6/8 pays 7:6 so multiples of 6 (e.g. 18); place 5/9 pays 7:5 so multiples of 5; place 4/10 pays 9:5 so multiples of 5; pass/come odds pay true odds: 4/10 2:1 (any amount), 5/9 3:2 (multiples of 2), 6/8 6:5 (multiples of 5); lay odds mirror (4/10 1:2 multiples of 2, 5/9 2:3 multiples of 3, 6/8 5:6 multiples of 6); hardways, big 6/8, field, props per their pay tables; horn multiples of 4 (already). Engine rejects (or UI snaps) amounts that are not a valid multiple. Bets can be ADDED and TAKEN DOWN in increments of the unit or whole, within the existing rules (pass/come line bets cannot be reduced once a point is set; place and odds can be). Chip denominations (1, 5, 25, 100) so stacks make change sensibly. Update tests and per-bet help text with the unit.
