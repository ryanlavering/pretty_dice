# Pretty Dice

Single-file Three.js prototype (`index.html`, no build). Serve with `python3 -m http.server 8123`.

- Tasks live in `backlog/` (backlog.md, prefix `pd`). Check `backlog/tasks` before starting; update status as you go. Add `PATH=$HOME/.local/opt/node/bin:$HOME/.local/npm-global/bin:$PATH` to use the `backlog` CLI.
- Tests: Playwright suite in `tests/` (design: `docs/design/testing.md`). `npm install` once, then `npm test` (host; skips screenshot baselines) or `npm run test:docker` (pinned image; the only place visual baselines are made/compared). Run `npm test` before moving a card to Needs Review. Test scripts take a machine-wide lock (`scripts/with-test-lock.sh`, `/tmp/pretty-dice-tests.lock`) so runs from several sessions queue instead of overloading the CPUs: always go through `npm test` (pass file filters after `--`), never a bare `npx playwright test`, and don't kill a run that isn't yours; every bug fix gets a regression test. Drive the app through `window.__pd` (pause/renderOnce/setView/simRoll/memory + live state getters); `?seed=N` makes looks and rolls reproducible. Ad-hoc checks: `node scripts/probe.mjs 'pd.simRoll()'`.
- Remaining legacy hooks (`?test=atlas|models`) move into the visual specs with PD-20.2; don't add new `?test=` hooks, write a spec. Physics/state-only specs use the `shared` fixture (one booted page per worker, `shared.reset(seed)` per test) because booting dominates test time. `?shape=`, `?sub=`, `?radius=` preselect a look.
- Settings persist in localStorage (`prettydice.v1`); clear it when testing defaults.
- Libraries: loaded from the CDN with a fallback to `vendor/` (see `vendor/README.md`). `python3 scripts/build-static.py` makes the single-file offline build in `dist/` (git-ignored). Keep the `<!--BOOTSTRAP-->` markers in `index.html`; the build script replaces that block. Test offline with chrome flag `--host-resolver-rules="MAP cdn.jsdelivr.net ~NOTFOUND, MAP fonts.googleapis.com ~NOTFOUND, MAP fonts.gstatic.com ~NOTFOUND"`.
