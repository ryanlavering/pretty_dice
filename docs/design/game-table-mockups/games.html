Pretty Dice: Game table

Design sketches for the v4.0 headline: built-in dice games with scoring. Dice, mat and roll feel stay exactly as they are. A game adds a rule set, a scorecard and turn handling around them. Everything below is one proposal for you to react to.

1. Finding a game

A fourth tab, Games, sits beside Shape, Sets and Log. Each card shows the dice it uses and how many people play. Tap one, set it up, and you land on the roll mat.

2. Yahtzee on a phone

The mat stays the star. Tapping a settled die holds it: it lifts and gets a gold ring. The big button rolls only the others. After the last roll, the scorecard sheet slides up and suggests what each box would score.

3. Craps

A state machine rather than a scorecard: come-out roll, point, pass and don't pass, odds, payouts. Play money only. The point puck sits on the mat showing ON and the number, flipping to OFF between rounds, like a real table.

4. On a wide screen

The mat takes the left; the scorecard lives in a permanent right column instead of a sheet. Same data, same taps.

5. How games are defined

Each game is a small data file, not code in the app: which dice, how many rolls, what can be held, how boxes score, when it ends. That keeps games testable, lets us add many, and later lets players share their own house variants.

{ "id": "farkle", "name": "Farkle", "players": [2, 8],
  "dice": "6 x design",
  "turn": { "rolls": "until-farkle-or-bank", "hold": "scoring-dice", "hotDice": true },
  "score": [ { "match": "single 1", "pts": 100 }, { "match": "single 5", "pts": 50 },
             { "match": "three of a kind", "pts": "face*100", "ones": 1000 },
             { "match": "straight 1-6", "pts": 1500 } ],
  "win": { "target": 10000, "finalRound": true } }

Craps and Liar's Dice have state (point, bets, hidden bids), so they get a small named “engine” alongside their data, not a pure table. Each engine is tested alone with seeded rolls.

Where this fits

Bag and dice

Games use the dice designs you already own. A game just says “6 dice” or “2 dice”; the look is yours.

Needs first

Hold a die (tap), per-die results readable by the app, and a turn/player model. Those are also what Characters needs later.

Out of scope for 4.0

Online play, real-money anything (Craps is play money only), and rules the player must type in.

Questions for you

Entry point

A Games tab beside Shape / Sets / Log, as drawn, or a launcher on the main mat screen?

Suggestions

Show what each scorecard box would score (drawn), on by default? It teaches the game but can feel like hand-holding.

Launch set

Yahtzee, Farkle, Pig, Craps first. Liar's Dice needs hidden dice and a pass-the-phone flow. Keep it for later?
