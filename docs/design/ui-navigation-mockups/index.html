Pretty Dice: navigation proposals

PD-142.38. Three ways to arrange the same app. Each frame is a sketch of layout and wording, not final styling. The gold button is the only roll control in its frame. The paired circles mark the one utility drawer.

Top stripWhere you are, the die name or total or game status, and the drawer. Hold the middle for the top-down look, as game mode does today.
DockThe one gold Roll button, with what it will throw beside it. In a game it takes the game's label: "Roll 3".
Drawer (paired circles)Sound, pause spin, reset camera, full view, hints. Opens as a wide pill, then slides shut.
