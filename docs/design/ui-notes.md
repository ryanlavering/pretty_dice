# UI notes (owner decisions)

## Collapsible menus on the mat (owner, 2026-11-13, PD-142.29)
Applies to any FUTURE collapsible menu; today Games is a plain always-visible button next to the bag button.
1. A menu starts in wide pill form showing its contents, then slides collapsed into a single button, so the user sees it exists.
2. The collapsed button carries a stack cue: a pair of overlapping circles (Mastercard-logo style) saying it is the top of a stack.
3. A collapsed menu never holds a single element: it needs 2 or more items, otherwise it stays a plain button.
4. Do not hide a primary entry point behind a long-press or right-click (the PD-142.8 tray was "not found in a million years"). Gestures may be extras only.
